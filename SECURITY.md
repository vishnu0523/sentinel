# Security policy

## Authorized use

This repository is a defensive assessment workspace. Use it only with written authorization and within the approved rules of engagement. The included fixture lab runs local educational models; it does not authorize testing production systems.

Do not commit secrets, access tokens, private reports, personal data, or unredacted sensitive evidence. Keep target-specific evidence in an approved private channel unless disclosure is explicitly authorized.

## Reporting a vulnerability in this project

Use GitHub private vulnerability reporting when it is enabled for the repository. Do not publish exploit details in a public issue before maintainers have had a reasonable opportunity to assess and remediate the report.

Reports should include the affected revision, prerequisites, minimal reproduction, impact, evidence, and a proposed remediation. Harmless local proofs are preferred.

## World Monitor findings

Follow the World Monitor maintainers' published security and disclosure process. This repository does not grant permission to probe their hosted service. Source observations, fixture failures, and theoretical risks must remain labelled as unverified until reproduced safely against an authorized target revision.
